# AI 网络守护（macOS）

一个本地运行的 macOS 悬浮小组件：用圆形蜘蛛侠风格图标展示当前网络状态，点击可展开出口 IP 面板。它通过 Ping0 免费接口查询出口 IP 与地区，在检测到中国大陆出口或连续查询失败时，可提醒或关闭 Claude、Gemini 和 Codex 桌面客户端。

## 功能

- 可拖动的圆形悬浮球，点击展开/收起详情
- 每 30 秒查询一次出口 IP、地区、ASN 和运营商
- 中国大陆 IP 连续命中 2 次后判定异常（港澳台排除）
- Ping0 查询连续失败 2 次时按“状态未知”保守处理
- 可选择仅提醒，或请求目标客户端退出；3 秒后仍未退出则强制关闭
- 菜单栏保留检测、显示组件和退出入口
- 一键打开 Shadowrocket 与 Ping0 详情页

## 构建

要求：macOS，已安装 Xcode Command Line Tools。

```bash
./build.sh
open "dist/AI网络守护.app"
```

`build.sh` 会编译、运行内置规则测试，并对应用进行本地临时签名。

## 使用

1. 启动 Shadowrocket 并确认代理已连接。
2. 打开 `AI网络守护.app`。
3. 点击蜘蛛侠悬浮球展开详情。
4. 如需自动保护，勾选“异常时自动关闭三个客户端”并确认风险。

## 重要限制

- Ping0 的免费接口只返回 IP、地区、ASN 和运营商；“纯净度/风控值”需在 Ping0 网页中查看。
- 本工具检测的是自身请求看到的出口。若 Shadowrocket 使用按应用分流，目标客户端可能走不同出口。
- 定时检测存在延迟，不能替代 Shadowrocket 的断线阻止联网（Kill Switch）能力。
- 自动关闭可能导致未保存内容丢失；首次使用建议保持“仅提醒”。
- 查询失败也可能是 Ping0 服务临时异常，并不必然代表代理断开。

## 隐私

应用不会上传文件、账号或对话内容。为查询出口网络信息，它会向 `https://ping0.cc/geo` 发出请求；该服务自然会看到请求的出口 IP。
